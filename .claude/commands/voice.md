Запусти локальный веб-сервер для голосового ввода командой: `python3 -m http.server 8765 &`

После запуска скажи пользователю:
"Сервер запущен! Теперь:
1. Открой вкладку **Ports** внизу VS Code
2. Найди порт **8765** — нажми значок 🌐 (Open in Browser)
3. Откроется страница голосового ввода в Chrome
4. Нажми 🎤, говори, затем нажми **Скопировать**
5. Вернись сюда и вставь текст (Ctrl+V)"
